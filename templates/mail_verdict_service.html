Envoi des comptes rendus — SMTP de la boîte source

Renseignez le SMTP autorisé à envoyer avec l’adresse de cette boîte. Un mot de passe vide conserve celui enregistré. Selon le fournisseur, utilisez un mot de passe d’application pour le SMTP, même avec une source IMAP connectée via OAuth2.

Le test SMTP envoie réellement un email au destinataire indiqué, même si Simulation est cochée. Les tests utilisent les valeurs saisies et les secrets enregistrés laissés vides ; cliquez ensuite sur Enregistrer pour les appliquer au service.

Traitement

Les clés, modèles et quotas sont ceux de l’administrateur principal ; les verdicts sont envoyés par le SMTP renseigné ci-dessus. Le score numérique est fourni uniquement si Rspamd est activé. Sa simulation globale reste prioritaire. Les listes blanche/noire ne court-circuitent pas le diagnostic de ce service.

Un seul dossier, sans récursion. Les réponses automatiques et listes de diffusion sont ignorées. Une adresse From peut être usurpée : utilisez une boîte de soumission dédiée. Le message est supprimé par UID après acceptation SMTP, sans toucher aux autres messages marqués supprimés. En cas d’envoi ambigu, aucun renvoi automatique ; vérifier les traces SMTP.
