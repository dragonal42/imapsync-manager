Antispam local Rspamd

Réglages globaux, appliqués aux prochaines exécutions. Rspamd seul conserve les scores intermédiaires ; avec prétri et IA, ils sont transmis à Mistral/Gemini. Les suspects locaux vont dans INBOX._03-Suspects. La simulation couvre aussi les listes et l’IA éventuelle, mais pas le transfert IMAP. Commencez en simulation pour calibrer les seuils.

Une analyse Rspamd à la fois. Le message complet est envoyé au service interne ; aucun contexte SMTP n’est inventé pour SPF/DMARC. Les vérifications DNS et réputation dépendent de votre configuration Rspamd. Aucun apprentissage n’est demandé par cette application.
